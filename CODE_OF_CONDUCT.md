# Code of Conduct

## Our Commitment

We are committed to making participation in this project a respectful and
harassment-free experience for everyone.

## Expected Behavior

- Be respectful and considerate in communication.
- Assume good intent and provide constructive feedback.
- Focus on what is best for the community and project.

## Unacceptable Behavior

- Harassment, threats, or discrimination.
- Personal attacks, trolling, or insulting language.
- Publishing private information without explicit permission.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, commits, and
other contributions that violate this Code of Conduct.

## Reporting

Please report unacceptable behavior by opening a private security advisory in
the repository.
