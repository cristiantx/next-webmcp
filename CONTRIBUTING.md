# Contributing

Thanks for contributing to `next-webmcp`.

## Development Setup

1. Use Node.js `>=20`.
2. Install dependencies:

```bash
npm ci
```

3. Run local checks:

```bash
npm run check
```

## Pull Requests

1. Keep PRs focused and small.
2. Include tests for behavioral changes.
3. Update docs when APIs or usage changes.
4. Explain the motivation and approach in the PR description.

## Reporting Issues

- Open a GitHub issue for bugs, feature requests, and questions.
- Include reproduction steps and environment details when possible.
